# Определение заполненности аудитории по фото

Учебный проект: backend принимает фотографию аудитории, запускает YOLOv8,
определяет людей и парты, привязывает людей к местам за партами и возвращает
число свободных мест.

Frontend специально сделан максимально простым: загрузка изображения, результат
и картинка с разметкой.

## Что используется

- Python 3.10+
- FastAPI
- YOLOv8 из пакета `ultralytics`
- OpenCV
- Простой HTML/CSS/JS frontend

## Установка

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

При первом запуске `ultralytics` автоматически скачает модель `yolo11m.pt` (YOLO11 Medium — новейшая архитектура, значительно точнее YOLOv8n).

Если виртуальное окружение уже создано внутри папки `backend`, можно выполнить:

```powershell
cd backend
.\venv\Scripts\Activate.ps1
pip install --upgrade -r requirements.txt
```

Если при запуске появляется ошибка PyTorch вида `Weights only load failed`,
обновите зависимости командой выше. Обычно это происходит из-за старой версии
`ultralytics` вместе с новым PyTorch.

## Запуск

```powershell
uvicorn backend.main:app --reload
```

После запуска откройте:

```text
http://127.0.0.1:8000
```

## Как работает алгоритм

1. YOLO11 ищет на фото людей (`person`), столы (`dining table`) и стулья
   (`chair`) из стандартного COCO-набора классов.
2. Так как в COCO нет отдельного класса "school desk", стандартная модель
   использует `dining table` как приближение к парте.
3. Если столы не найдены, включается fallback: соседние стулья в одном ряду
   группируются в одну парту.
4. Каждая парта считается двухместной.
5. Парта делится на левое и правое место.
6. Для каждого человека берется нижняя центральная точка bounding box, потому
   что для сидящего человека она обычно ближе к месту за партой.
7. Если точка человека попадает в расширенную область места, место считается
   занятым.
8. Итог: `свободные места = всего мест - занятые места`.

## Важное ограничение

Стандартная `yolo11m.pt` обучена на COCO и не знает точный класс "парта".
Для демонстрационного учебного проекта этого достаточно, но для стабильной
работы на фотографиях аудиторий лучше дообучить YOLO11 на своих размеченных
данных с классами:

- `person`
- `desk`

Тогда в `backend/detector.py` нужно будет заменить класс `dining table` на
класс вашей кастомной `desk`-модели и обновить путь к весам в `ClassroomDetector`.

## API

### `POST /api/analyze`

Поле формы:

- `file` - изображение аудитории.

Ответ содержит:

- `free_seats` - число свободных мест;
- `occupied_seats` - число занятых мест;
- `total_seats` - общее число найденных мест;
- `desks` - список парт и мест;
- `annotated_image` - изображение с разметкой в base64.
